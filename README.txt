Level 1 Speaking Trainer - v7

이번 수정
- '문제 수'를 '학습 문장 수'로 변경
- 선택한 학습 단계에 따라 실제 총 연습 횟수를 자동 표시
  예) 학습 문장 수 10개 + 전체 코스 = 총 30회 연습
  예) 학습 문장 수 10개 + 2단계만 = 총 10회 연습
- 선택한 과 묶음에서 사용 가능한 전체 문장 수 표시
- 문제 진행 표시를 '1단계 · 문장 3 / 10'처럼 더 직관적으로 변경

기존 기능
- 1과~46과 전체
- 전체 코스 / 1단계 / 2단계 / 3단계
- 자동 한글 읽기
- 음성 선택
- 오답 집중
- 전체 랜덤
